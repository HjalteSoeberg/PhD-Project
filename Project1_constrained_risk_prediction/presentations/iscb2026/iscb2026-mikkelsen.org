*** Setting: competing risks
Notation
\vfill
- $T$: the time between time zero[fn:1] and the date of an event
- $D\in\{1,2\}$: the cause of the event
- $X = (X^1,...,X^p)$: a p-dimensional vector of baseline covariates
- $C$: the time between time zero and censoring
- $\widetilde{T} = \min(T,C)$: observed time
- $\Delta = 1\{T\leq C\}$: censoring indicator
- $\widetilde{D} = \Delta D$: observed event
- $\tau$: prediction time horizon

 
 \vfill
We assume conditional independent censoring and that the probability of being censored at time \(\tau\) is bounded away from zero for all $x$. 
# Additionally we assume that the event time $T$ is right censored at the random time $C$, where $P(C>\tau\vert X)>0$ almost surely. Denote $\widetilde{T} = \min(T,C)$ and $\widetilde{D} = \Delta D$ as the observed time and event, where $\Delta = 1\{T\leq C\}$.
[fn:1] Any time in the life of a person


*** The parametric Cox-exponential model

For both causes $j\in\{1,2\}$ and censoring $j = 0$, specify Cox regression models with constant baseline hazards:
#+begin_export latex
\begin{align*}
\lambda_j(t\mid x) &=\lambda_{0j}\exp(x^\top\boldsymbol{\beta}_j),\qquad \lambda_{0j}>0,\\
\Lambda_j(t|x) &= \int^t_0\lambda_j(s|x)ds = t\lambda_j(t|x)
\end{align*}
#+end_export
\pause
The observed cause-specific cumulative incidence functions:
#+begin_export latex
\begin{align*}
\widetilde{F}_j(t|x) &= P(\widetilde{T}\leq t, \widetilde{D} = j|x)\\
&= \int_0^t \exp\{-\Lambda_1(s-|x)-\Lambda_2(s-|x)-\Lambda_0(s-|x)\}\Lambda_j(ds|x)
\end{align*}
#+end_export

#  Let $\widetilde{A}(x)=\sum_{j=0}^{2}\lambda_{0j}\exp(x^\top\boldsymbol{\beta}_j)$. Then
# \[
# \widetilde{F}_j(\tau\mid x)=\frac{\lambda_{0j}\exp(x^\top\boldsymbol{\beta}_j)}{\widetilde{A}(x)}
# \{1-\exp[-\tau \widetilde{A}(x)]\}.
# \]

# All parameter sets $(\boldsymbol{\beta}_0,\lambda_{00})$, $(\boldsymbol{\beta}_1,\lambda_{01})$ and $(\boldsymbol{\beta}_2,\lambda_{02})$ are
# estimated simultaniously by minimizing the Brier score loss.


*** Estimation of observed risks [fn:2]

# Let $\widetilde{F}_j(t|x) = P(\widetilde{T}\leq t, \widetilde{D} = j|x)$
#+begin_export latex
\begin{block}{Brier-score loss function}
\[
BSE=
\frac{1}{N}\sum_{i=1}^{N}\sum_{j=0}^{2}
\{\widetilde{F}_j(\tau\mid X_i)-1(\widetilde{D}_i= j,\widetilde{T}_i\leq \tau)\}^{2}.
\]
\end{block}
#+end_export
\pause

- Estimating the parameters of the three Cox-exponential models by minimizing the overall Brier score yields \(\hat\Lambda_1,\hat\Lambda_2, \hat\Lambda_0\) 
# - One loss function estimates the two cause-specific models *simultaneously*.
- No need for IPC weights
- Derive estimates of the absolute risks of both events \(\hat F_1, \hat F_2\) based on \(\hat\Lambda_1,\hat\Lambda_2\)
# - $\Theta$ encodes coherence: $F_j\geq0$ and $F_0+F_1+F_2=1$.
# Here the sum starts at $j = 0$ which is a method for handling right censoring \cite{munch}.

[fn:2] Munch & Gerds (2026). The joint survival super learner: A super learner for right-censored data. Statistica Neerlandica, 80(2), e70026.

* From framework to learner

*** COMMENT Maximum likelihood
# this is not the full likelihood, missing censoring
Assume we have $N$ observations of $(\widetilde{T},\widetilde{D}, X)$. Using that the survival function is a product of the individual cause-specific survival functions, $S(t_i|x_i) = \prod S_j(t_i|x_i)$, we can write the likelihood as
#+begin_export latex
\begin{align*}
L = \prod_{j = 1}^2\prod_{i = 1}^N\lambda_{j}(t_i|x_i)^{d_{ij}}\exp(-\Lambda_j(t_i|x_i)),
\end{align*}
#+end_export
where $d_{ij} = 1\{\widetilde{D}_i = j\}$. \pause This means that the likelihood function is a product of 2 likelihoods, one for each cause. We can then maximize each cause-specific likelihood function seperately by choosing some parametric form for the baseline hazards.


*** Brier score estimation
# #+begin_export latex
# \begin{align*}
# \hat{\theta}_{BSE}=&\arg\min_{\theta}\frac{1}{N}\sum_{i=1}^{N}\sum_{j=0}^{2}\\
# &\{\frac{\lambda_{0j}\exp(x_i^\top\boldsymbol{\beta}_j)}{\widetilde{A}(x_i)}\{1-\exp[-\tau \widetilde{A}(x_i)]\}-1(\widetilde{D}_i= j,\widetilde{T}_i\leq \tau)\}^{2}.
# \end{align*}
# #+end_export
Parameter vector and the estimator:
#+begin_export latex
\begin{align*}
{\theta} &= (\lambda_{00},\boldsymbol{\beta}_0,\lambda_{01},\boldsymbol{\beta}_1,\lambda_{02},\boldsymbol{\beta}_2), \\
\hat{\theta}_{BSE}&=\arg\min_{\theta}\frac{1}{N}\sum_{i=1}^{N}\sum_{j=0}^{2}
%\{\int_0^t \exp\{-\sum_{k = 0}^2\Lambda_k(s-|x)\}\Lambda_j(ds|x)
\left\{\widetilde F_j(\tau|x;\theta)-1(\widetilde{D}_i= j,\widetilde{T}_i\leq \tau)\right\}^{2}.
\end{align*}
#+end_export

\pause \vfill
Cause specific risk predictions can then be obtained by substituting $\hat \theta_{BSE}$ into:
#+begin_export latex
\begin{align*}
F_j(t|x) &= P(T\leq t, D = j|x)\\
&= \int_0^t \exp\{-\Lambda_1(s-|x;\theta)-\Lambda_2(s-|x;\theta)\} \Lambda_j(ds|x;\theta)
\end{align*}
#+end_export

# Let $\hat{A}(x)=\sum_{j=1}^{2}\hat{\lambda}_{0j}\exp(x^\top\hat{\boldsymbol{\beta}}_j)$,
# #+begin_export latex
# \begin{align*}
# F_j(\tau|x) = \frac{\hat{\lambda}_{0j}\exp(x^\top\hat{\boldsymbol{\beta}}_j)}{\hat{A}(x)}
# \{1-\exp[-\tau \hat{A}(x)]\}, \text{ for }j\in\{1,2\}
# \end{align*}
# #+end_export

*** Why estimate like this?

*Working hypothesis:* 

The Cox-exponential model makes sense as we only need predictions for one specific timepoint, so we don't need the baseline hazard to vary over time.
\vfill

Estimating both cause-specific hazards this way:
- targets calibration and discrimination directly at the prediction horizon
- performs well in non-proportional hazards data
- respects the parameter space, i.e., \(F_1 + F_2 \leq 1\)
- produces a portable parametric learner for use outside protected enviroments.

*** Artificial censoring at the prediction horizon

Artificial censoring replaces the observed outcome by
\[
\widetilde T_i^{(4)}=\min(\widetilde T_i,4),\qquad
\widetilde D_i^{(4)}=\widetilde D_i1\{\widetilde T_i\leq4\}.
\]
It removes all event-time information after the four-year horizon. This affects the estimates of Cox models fitted using likelihood methods.

#+begin_export latex
\begin{columns}[T]
\begin{column}{0.47\textwidth}
\begin{block}{It can lose predictive power}
If proportional hazards is correct, later events inform the same $\boldsymbol{\beta}_j$ that
governs hazards before four years. Discarding them wastes information.
\end{block}
\end{column}
\begin{column}{0.47\textwidth}
\begin{block}{It can gain predictive power}
If effects change after four years, an untruncated Cox fit compromises across
periods and can learn the wrong effect for the four-year target.
\end{block}
\end{column}
\end{columns}
#+end_export

*** COMMENT The Cox-exponential Brier-score estimator changes the question

Likelihood-based Cox estimation asks:
\begin{center}
``Which hazard parameters best explain all observed event times?''
\end{center}
The proposed estimator asks:
\begin{center}
``Which two models best predict each person's state at $\tau=5$ years?''
\end{center}

The Brier target is inherently horizon-specific. Follow-up after $\tau$ does not contribute to the outcome, while censoring before $\tau$ still
has to be handled by the censoring model/weights.

*** COMMENT Take-home message

#+begin_export latex
\begin{block}{Main contribution}
Use one multivariate Brier loss at the prespecified horizon to estimate both
cause-specific hazard models simultaneously.
\end{block}
#+end_export

- The estimand is explicit: diabetes and death without diabetes by five years.
- Coherence is guaranteed during estimation, not repaired afterwards.
- The models can be exported from protected environments.
- This is an additional model one can add to their library of learners when using Super Learning.
